# 城市社区银龄志愿服务报名排班积分兑换平台

面向城市社区老年志愿者的一体化管理平台：覆盖 **报名登记 → 培训 → 保险 → 岗位发布 → 智能排班 → 签到 → 服务确认 → 积分入账 → 积分兑换 → 异常处理 → 关怀回访** 的完整闭环。所有环节写入同一条 **志愿档案时间线**，发生身体不适或投诉时可完整还原过程。

## 功能总览

**社区工作端（admin）**
- 总览看板：队伍稳定性（活跃人数、缺勤率、平均评价、健康分布）、服务覆盖（6 类岗位的岗位数/完成次数/服务时长）、安全与权益提醒（保险失效名单、待回访、未结投诉、兑换失败、家属反对人数）
- 志愿者档案：报名登记（年龄、健康情况、擅长技能、可服务时间、紧急联系人、是否需要家属知情）、培训记录、保险状态、积分流水、**志愿档案时间线**
- 岗位管理：发布图书整理、文明劝导、助餐引导、儿童阅读陪伴、邻里调解、活动签到等岗位，填写服务地点、时长、风险等级、人数、积分规则
- 智能排班：按 **技能匹配(30) + 距离(20) + 健康风险适配(20) + 培训合格(20) + 历史评价(10)** 打分推荐；保险失效、家属反对高强度、健康较弱、缺少合格培训、时间不匹配、距离过远者 **硬性拦截**
- 服务管理：代签到、完成确认（照片或负责人确认）、评价打分、标记缺勤、取消排班
- 积分兑换：兑换项目管理（食堂餐券/理发券/体检优惠/公益荣誉）、库存管理、兑换记录（含库存不足失败记录）
- 投诉处理：登记服务对象投诉，自动生成关怀回访任务
- 关怀回访：身体不适、临时缺勤、投诉、岗位风险升级等自动触发回访任务，回访结果记入档案

**志愿者端（老年志愿者账号）**
- 我的服务任务：查看排班、签到/拍照签到、上传服务照片完成服务、身体不适一键取消（自动触发关怀回访）
- 我的积分与兑换：积分余额、积分流水、兑换商品（库存不足/积分不足自动拦截并记录）
- 我的志愿档案：个人全量志愿服务时间线、培训记录、保险状态

**安全边界与权益保护（平台硬性规则）**
- 中高风险岗位：保险必须在有效期内，否则不可排班
- 高风险岗位：家属反对或需家属知情但未确认、健康状况较弱者不可排班
- 岗位风险升级：自动重新评估已排班志愿者，不再适合者自动取消排班并生成关怀回访
- 积分兑换库存不足：兑换失败、积分不扣减、失败原因记入档案，看板提醒社区补货
- 临时缺勤/身体不适：自动生成关怀回访任务，保护老年志愿者积极性与安全

## 技术栈

- 前端：React 18 + Vite + Ant Design 5 + React Router 6
- 后端：NestJS 10 + TypeORM 0.3 + JWT（scrypt 密码哈希）
- 数据库：PostgreSQL 16（TypeORM synchronize 自动建表，首次启动自动写入演示数据）

## 一键启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问：

| 入口 | 地址 |
| --- | --- |
| 平台页面（前端） | http://localhost:8080 |
| 后端 API | http://localhost:3000/api |
| PostgreSQL | localhost:5432（postgres/postgres，库 silver_volunteer） |

首次启动后端会自动建表并写入演示数据（5 名志愿者、6 类岗位、培训/保险记录、兑换商品、历史服务记录）。停止并清空数据：`docker compose down -v`。

## 本地开发启动

需要 Node.js ≥ 18 与 PostgreSQL（本地或容器均可）：

```bash
# 1. 准备数据库（任选其一）
docker run -d --name pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=silver_volunteer -p 5432:5432 postgres:16-alpine
# 或使用已有 PostgreSQL：createdb silver_volunteer

# 2. 后端（默认连接 localhost:5432，可用 DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME 覆盖）
cd backend
npm install
npm run start:dev        # 或 npm run build && npm start
# 后端运行在 http://localhost:3000/api

# 3. 前端（另开终端，已配置 /api 代理到 3000）
cd frontend
npm install
npm run dev              # http://localhost:5173
```

```bash

API_BASE=http://localhost:8080/api node scripts/e2e-test.mjs   # 也可走前端 nginx 代理
```

覆盖：登录认证、报名登记、培训/保险登记、智能推荐（含保险失效/家属反对/缺培训/时间不匹配拦截）、排班、重复排班拦截、签到、负责人确认完成、积分入账、兑换成功、**库存不足兑换失败**、身体不适取消并自动回访、临时缺勤并自动回访、投诉登记与办结、回访归档、**岗位风险升级自动取消不合格排班**、统计看板、越权访问拦截。
